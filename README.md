# CHO KAN ZU — カラス版

**再生ボタンを一度押すだけで、ロビーからカラスの視点へ移り、夜の都市を飛んで写真展に到着する約40秒の演出です。到着後は展示室を自由に見回せます。**

制作方針・変更履歴・素材の扱いは [制作方針と変更記録.md](制作方針と変更記録.md) に記録しています。

## 開く

- `index.html` をブラウザで開き、「フライトを再生」を押します。
- ローカルプレビュー: `npm start` → `http://127.0.0.1:4174`
- Three.js、GLBモデル、床、写真をHTMLに同梱。再生のための外部通信はありません。

## 操作

- ▶ / Ⅱ: 再生と一時停止。移動はすべて自動です。
- ↺: 最初から再生。
- 下のバー: 再生位置を調整。
- 「表示を隠す」または **H**: 画面内の文字と操作ボタンを非表示。画面をクリック・タップ、H、またはEscで戻せます。
- 音: 初期状態はOFF。ONにするとローカル合成の風と静かな音が鳴ります。
- 展示室に到着すると、高度・再生バー・再生操作は消え、右下に小さな「最初から」ボタンが出ます。
- 展示室では画面をドラッグして見回します。
- スマートフォン・狭い画面では左下の丸いスティックを指で倒すと移動します。指を離すと止まります。見回しと移動は別々の指でも操作できます。
- PCではドラッグで見回し、矢印キーで前後左右へ移動します。
- 展示されている写真をタップすると、障害物を避けて正面へ自動移動します。ドラッグやスティック操作で中断できます。
- 正面に移動した写真をもう一度タップすると拡大表示します。前後の写真送りも使えます。
- 別タブに切り替えたときは一時停止します。戻ってから再開できます。

SNS用には表示を隠して画面収録してください。ブラウザの外枠は収録アプリ側で調整します。この版はWebで再生する演出で、MP4の書き出しは含みません。

## 素材

- カラス: ユーザー提供の `カラス.glb` をglTF Transform 4.5.0で軽量化した `assets/models/crow.glb`（約2.69MB）を使用。画像2枚を4K PNGから2K WebP（品質92）へ変更し、形状は維持。金属の質感を保ち、台座に合わせて高さを調整しています。元のダウンロードファイルは編集していません。
- 飛行中の翼: GLBには骨・アニメーションがないため、同じ方向性の金属板・ヒンジ・支柱で作成した独立した翼を使用。
- 床: ユーザーが最後に指定した星空画像を `assets/星空の床.png` に保存。縦横比を保ち、星と星座が足元で見える大きさで床全体に敷いています。旧 `assets/床.webp` は未使用で保管。
- 写真: ユーザーが差し替えた `assets/photos/01.webp`〜`10.webp` の10点。作品名と作者名は未指定のため、画面では番号だけ表示します。旧サンプルの作品名・Unsplash表記は使用しません。
- 外部素材の追加取得や有料サービスは利用していません。

## 編集

```sh
npm install
npm run build
npm start
```

この作業環境では親フォルダに既存の依存パッケージがあるので、それを読み取り利用してビルドできます。フォルダ単独で編集を続ける場合は上の手順で依存パッケージを用意してください。配布用 `index.html` の再生にNode.jsは不要です。

- `src/main.js`: 到着までの時間軸、カメラ、写真の閲覧、操作。
- `src/gallery-controls.js`: 到着後のドラッグ見回し、丸い移動スティック、写真への自動移動。
- `src/world.js`: 継承したロビーの建築と点灯。エレベーターはありません。
- `src/crow.js`: 提供GLBの読み込みと、機械的な一人称の翼。
- `src/city.js`: 278棟の立体ビルと飛行経路、空、都市の灯り。
- `src/gallery.js`: 写真展示空間・写真選択・安全な移動経路。毎回同じ順で写真が現れます。
- `src/gallery-assets.js`: 床と写真の読み込み一覧。
- `src/audio.js`: 合成音。
- `src/template.html` / `src/style.css`: 画面表示。

カラス差し替え時は非同期の `createCrow()` の `root` と `headTarget`（憑依するときに近づく眼の位置）、`update()` を境界に利用できます。飛行時の翼は `createFlightWings()` で独立しています。

画面左下の01〜06の章番号・英語見出し・説明は削除済みです。ヘッダーは「CHO KAN ZU」と羽のSVGです。

## GitHub Pages向けのファイル

- 公開用ファイルは、このフォルダの `index.html` 1つで足ります。GLB、写真、床、プログラムをすべて同梱しています。
- 軽量化後のHTMLは約13.22MB。ビルド時に25,000,000バイト未満か検査し、超えた場合はエラーにします。
- 編集用のファイルも保管する場合は `src/`、`assets/`、ビルド設定などもリポジトリに含めます。`node_modules/` と `.verification/` は `.gitignore` で除外しています。
- モデルの画像にはWebPを使用しています。現在の主要ブラウザ向けです。

軽量化に使ったコマンド（glTF Transform 4.5.0）:

```sh
gltf-transform resize /path/to/original.glb crow-2k.glb --width 2048 --height 2048
gltf-transform webp crow-2k.glb assets/models/crow.glb --quality 92 --effort 80
```

中間ファイル `crow-2k.glb` は変換完了後に不要です。元データは別に保管してください。
